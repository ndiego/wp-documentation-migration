# Writing & publishing

How to create and publish content in WordPress: writing posts and pages, controlling who can see
them and when, using excerpts and revisions, and organising your site so visitors can find things.

These pages describe the block editor. For the editor itself, see **Block editor** under
**Editing & design**; Classic Editor versions of these tasks are in **Classic WordPress**.
