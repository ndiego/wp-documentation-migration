# Writing & publishing

How to create and publish content in WordPress: writing posts and pages, controlling who can see
them and when, using excerpts and revisions, and organising your site so visitors can find things.

Where a task works differently in the Classic Editor, the Classic Editor version follows directly
after the block editor one. For the editor itself, see **Block editor** under
**Editing & design**.
