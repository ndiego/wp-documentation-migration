# Default themes

Every year or so, WordPress ships a new default theme named after the year it was designed for.
This section covers the default block themes, starting with Twenty Twenty-Two, the first one.
Each page describes the theme's features and how to customise it in the Site Editor, and links
to the theme's changelog. Themes are listed newest first.

The classic default themes, from Twenty Twenty-One back to Twenty Ten, are documented in
[Classic default themes](../../../classic-wordpress/classic-default-themes/README.md).
