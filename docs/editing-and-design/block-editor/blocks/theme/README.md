# Theme blocks

Theme blocks help you build your site's templates in the Site Editor. They display content
that changes with context, such as the site title and logo, navigation, the post title,
content and date, query loops, and comments.

Most theme blocks are only available in block themes. Open the Site Editor
(Appearance > Editor) and use the block inserter to add them to a template or template part.
