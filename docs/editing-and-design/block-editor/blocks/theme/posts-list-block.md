# Posts List block

> [!WARNING]
> “WordPress 6.7 has removed this block variation. To create a list of posts, use the [Query Loop block](query-loop-block.md) or the [Latest Posts block](../widgets/latest-posts-block.md)“

The **Posts List block** is a variation of the **[Query Loop block](query-loop-block.md)** that lets you display posts based on various query parameters and visual configurations. It has various integrated block patterns to help you quickly set up the block appearance and layout.

To add a **Posts List block**, click the **Add block** button and select the **Posts List** block. Alternatively, type <kbd>/posts list</kbd>in a new paragraph block and press <kbd>Enter</kbd>.

Refer to this article for [detailed instructions on adding blocks](../../wordpress-block-editor.md#adding-a-block).

Note that once the block is added, you will see a placeholder for the block with the option to choose a block pattern or to start blank. However, note that on the block settings panel and the list view, the Posts List block is registered as a [Query Loop block](query-loop-block.md).

The Posts List block has the same setup process and configuration options as the Query Loop block.

Refer to this article for a more detailed guide for the [Query Loop block](query-loop-block.md).
