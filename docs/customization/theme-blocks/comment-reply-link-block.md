# Comment Reply Link block

[Go to the List of Blocks](../block-editor/blocks-list.md)

The *Comment Reply Link* block displays a link to reply to a comment. This block is located inside a Comment Query Loop block and lets you customize the appearance of the *Reply* link.

![Comment Reply Link Block](../../assets/images/external/lh4.googleusercontent.com/c89d325764-cWT79rdQMCx4VWg7sAETiqxGkKutyslXenkCTQ6h7-5VK3b_jiEsetjlvc-k.img)

> [!NOTE]
> You can only insert the *Comment Reply Link block inside* a Comment Template block within the Comment Query Loop block.

Click the (+) icon inside the comment template block to open the block inserter pop-up window and search for the *Comment Reply Link* block.

You can also use the keyboard shortcut <kbd>/comment-reply-link</kbd> to quickly insert a *Comment Reply Link* block inside a Comment Template block.

![How to quickly add a Comment Reply Link Block](../../assets/images/external/lh6.googleusercontent.com/e77fc7b186-iYZ4D7kCYQJMwGcjDp3FMUY0kpZQJuBKeurt14ZOR_u4Zrh8h3NsK3yQ7Xbs.img)

> [!NOTE]
> [Detailed instructions on adding blocks](../block-editor/adding-a-new-block.md)

## Block toolbar

![Block toolbar in the Comment Reply Link Block](../../assets/images/external/lh5.googleusercontent.com/858ae6ec01-lNRHlWYFIelkrfyg9CAFRShjSpfOMbOBgJkJcOHHjypQXgxjhDQl9X04KqwE.img)

The block toolbar contains the tools to customize each block. The *Comment Reply Link* block’s toolbar consists of the following tools:

**Transform to**

You can transform a *Comment Reply Link* block into a Columns block or a Group block.

![Transform option in the Comment Reply Link Block](../../assets/images/external/lh4.googleusercontent.com/b576a1c670-gnIqV5uV0OIfiaK2x-BUPLCkOI4548Qd0hJD-y3ldvP-qB7xZp1ZSQHcDvjw.img)

**Block-moving tools**

![Block moving tools in the Comment Reply Link Block](../../assets/images/external/lh6.googleusercontent.com/8170f31f57-7DZX_Sy54a8h7m0x7CXCPFyAA046qBYnftJnDhHjOtHGxMkq6WfZLLEKpNgU.img)

Use the block-moving tools to move the block up and down inside the editor. Use the six dots icon to drag and drop the *Comment Reply Link* block and reposition it anywhere on the editor. Alternatively, click on the up and down arrows to move the block up or down the editor.

**Change text alignment**

![Change text alignment in the Comment Reply Link Block](../../assets/images/external/lh3.googleusercontent.com/a2124d4695-i4mFdo54SiswmOIfTratt8kHceJuBp8XWwWHGvS3ZHA3hdoMRfyAQl8e3bUU.img)

Text alignment options let you align the Reply button towards the left, center, or right.

**More options**

![](../../assets/images/external/lh3.googleusercontent.com/3d6f0d8bb7-STpEOnzAff485usY4wV4EWog6XvyZz7kXet8dePFOESCiUW38aYuiqyxwnoI.img)

The [More Options menu](../block-editor/more-options.md) represented by **three vertical dots on the far right of the toolbar** gives you more features such as the ability to duplicate, remove, or edit your block as HTML.

> [!NOTE]
> [Read about these and other settings.](../block-editor/more-options.md)

## Block settings

The block settings panel contains customization options specific to the block. To open it, select the block and click the cog icon next to the Publish button.

![The cog icon next to the Publish button to show the Block settings](../../assets/images/external/lh4.googleusercontent.com/eaa186aa39-Yh34vXwF92YwMp2jOSKVSKMpsAbkggYwgCPEOc-2kkaA0mzXRaK-lad0x2sY.img)

Here are the options for the *Comment Reply Link* block:

### Color

The Comment Reply Link block lets you customize the background and link color.

Click on any of the options to change the color. Choose from the default color or click the upper rectangle area to pick a custom color using the color picker.

![Colors settings in the Comment Reply Link Block](../../assets/images/external/lh3.googleusercontent.com/f3a2dced89-fTt-F0jsjYojMenFEruc2FXNbcF-Wm_acdFqQ2xca2rWSokleO6B8JKNlyGM.img)

> [!NOTE]
> [See this guide for more information about changing colors.](../block-editor/colors-settings-overview.md)

### Typography

![Typography settings in the Comment Reply Link Block](../../assets/images/external/lh5.googleusercontent.com/a9c1aff6df-RYDugclKXg_6D0PM1UbRYiDPUiqKfL2zoKV_Mnx3__RIfF1N4NIWwiuQfrpY.img)
