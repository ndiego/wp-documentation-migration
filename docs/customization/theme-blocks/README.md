# Theme blocks

Theme Blocks are a collection of blocks specifically designed to help you customize and build your WordPress theme directly in the Site Editor. These blocks allow you to create dynamic and visually appealing layouts while maintaining full control over your site's design. To use Theme Blocks, open the Site Editor (Appearance > Editor) and navigate to the template or template part you want to edit. For more detailed instructions, explore individual block guides linked below.
