# Categories List block

[Go to the List of Blocks](../block-editor/blocks-list.md)

The Categories List block organizes your previously published posts by category. This can be handy for readers who want to find more of your posts about certain topics.

<video controls preload="metadata" src="https://wordpress.org/documentation/files/2019/03/Kapture-2026-04-20-at-15.26.48.mp4" poster="../../assets/images/2019/03/Screenshot-2026-04-20-at-3.29.50-PM.jpg"></video>

*Adding a Categories List block to the page and selecting options to change how the list is displayed*

## Add a Categories List block

The Categories List block can be added to a page by clicking on the **Block Inserter** button. You can find the Categories List block listed under the Widgets section.

![Add a categories list block with the slash command](../../assets/images/2019/03/Screenshot-2026-04-20-at-3.18.58-PM.png)

Alternatively, you can type <kbd>/categories</kbd> to select the Categories List block and hit enter in a new paragraph block to add one quickly.

> [!NOTE]
> [Detailed instructions on adding blocks](../block-editor/adding-a-new-block.md)

## Block toolbar

Each block has its own block-specific controls that allow you to manipulate the block right in the editor. The Categories List block has the following options in the Block toolbar.

![Block toolbar in the Categories List block](../../assets/images/2022/08/Screen-Shot-2022-08-04-at-3.33.36-PM.png)

*Categories list block toolbar*

### Transform to

You can transform a Categories List block into a Group, Details, Columns or Tag Cloud block.

![Categories List block transform options](../../assets/images/2019/03/Screenshot-2026-04-20-at-3.21.02-PM.png)

#### Move controls

![Block moving tools in the Categories List block](../../assets/images/2022/08/Screen-Shot-2022-08-04-at-3.33.44-PM.png)

*Block moving tools inside Categories List block toolbar*

Use the block-moving tools to move the block up and down inside the editor. Use the six dots icon to drag and drop the Categories List block and reposition it anywhere on the editor. Alternatively, click on the up and down arrows to move the block up or down the editor.

> [!NOTE]
> [Get more information about moving a block within the editor.](../block-editor/moving-blocks.md)

#### Change alignment

The **change alignment** tool lets you align the Categories List block within the content. You can choose one of the following alignment options:

<img src="../../assets/images/2022/08/Screen-Shot-2022-08-04-at-3.45.09-PM-1.png" alt="Change alignment in the Categories List block" width="231">

_Change alignment in the *Categories List* block_

-   **None** – Leaves the block alignment as is.
-   **Wide width** – Increase the width of the block beyond the content size.
-   **Full width** – Extend the block to cover the full width of the screen (if supported by your site’s theme).
-   **Align left** –Align the block to the left of the content.
-   **Align center** –Align the block to the center of the content.
-   **Align right** –Align the block to the right of the content.

#### More options

These controls give you the option to copy, duplicate, and edit your block as HTML.

> [!NOTE]
> [Read about these and other settings.](../block-editor/more-options.md)

## Block settings

Every block has specific options in the editor sidebar in addition to the options found in the block toolbar. If you do not see the sidebar, click on the **Settings button** next to the Save/Publish button.

![Block settings button highlighted](../../assets/images/2019/03/block-settings-Screenshot-2026-03-08-at-8.13.56-AM-1-1-3.png)

Every block has specific options in the editor sidebar in addition to the options found in the block toolbar. If you do not see the sidebar, click on the **Settings button** next to the Save/Publish button.

The Image block settings panel is divided into three tabs – Settings and Styles.

### Settings

The Categories List settings allow you to choose whether to display the categories list as a dropdown, or the default bulleted list. You also have the choice to show/hide the hierarchy, the top-level categories only, and the post counts.

![Block settings in the sidebar for Categories List block](../../assets/images/2023/05/Screenshot-2023-05-23-at-8.17.44-AM.png)

*Categories List Settings in the sidebar*

#### Display as dropdown

Choose this option to display the categories in a dropdown menu rather than as a list. This is handy if you want to save space or have a lot of categories.

![Categories displayed as dropdown](../../assets/images/2022/08/Screen-Shot-2022-08-04-at-4.05.10-PM.png)

*Categories displayed as dropdown*

#### Show post counts

If this option is chosen, the total number of published posts for each category will be displayed next to the category link. You can show post counts in both the list and dropdown display formats.

![Categories with post counts shown](../../assets/images/2022/08/171647939-ebeb8c27-7976-4c57-a037-cf7e45b633cd.png)

*Categories list block with post counts shown*

#### Show only top-level categories

If you have parent and child categories (subcategories within main categories) you can choose to display only the top-level category.

#### Show empty categories

You have the option to show or hide empty categories in the categories list.

#### Show hierarchy

If you have parent and child categories (subcategories within main categories) you can choose to display the hierarchy or just leave the list without indicating which subcategories fit inside your main categories. You can show category hierarchies in both the list and dropdown display formats.

![Categories with hierarchy shown](../../assets/images/2022/08/171647777-2cce2e2a-a3ac-433e-83bb-436d68b3e820.png)

*Categories list with hierarchy shown*

### Styles

The Categories List block provides options for styling color, typography, spacing/dimensions, and borders.

### Color

The Categories List block provides Color settings option to change test, link, and background colors.

> [!NOTE]
> [Learn more about changing colors](../block-editor/colors-settings-overview.md).

#### Typography

The Typography settings enable you to customize the apperance of text inside the Categories List block like font size, font family, letter spacing, and more.

> [!NOTE]
> [Get more details about changing typography settings](../block-editor/typography-settings-overview.md)

#### Dimensions

The Categories List block provides dimension settings options to add padding and margin.

> [!NOTE]
> [Learn more about dimension controls](../block-editor/dimension-controls-overview.md)

#### Border

The Categories List block provides border settings options to add border color, width, and radius.

> [!NOTE]
> [Learn more about border settings](../block-editor/border-settings-overview.md)

#### Advanced settings

The Categories List block provides the following Advanced settings options: HTML anchor, Additional CSS Class(es), Additional CSS, and Styles.

> [!NOTE]
> [Learn more about advanced settings](../block-editor/advanced-settings-overview.md)
