# Use character entities

## Character Entities or Extended Characters

In many WordPress sites, you will see odd symbols that will pop up from time to time. Often these symbols appear in navigation links. For instance, look at the the double left angle quotes **(«)** and the double right angle quotes **(»)** in this example:

```
« « Previous Post Title    |    Next Post Title » »
```

These symbols are called **[HTML](../../wordpress-overview/where-to-start/wordpress-glossary.md#html) character entities** or **extended characters**. They are generated by strange looking code on the web page that the web browser interprets as symbols.

The code that generated the above example looks like this:

```
<?php previous_post_link('&laquo; &laquo; %', '', 'yes'); ?>
| <?php next_post_link('% &raquo; &raquo; ', '', 'yes'); ?>
```

Some of the most popular [HTML](../../wordpress-overview/where-to-start/wordpress-glossary.md#html) *character entities* are:

|  |  |  |
| --- | --- | --- |
| &amp;raquo; | » | double right angle quote |
| &amp;laquo; | « | double left angle quote |
| &amp;lt; | < | single left arrow (left angle bracket) |
| &amp;gt; | > | single right arrow (right angle bracket) |
| &amp;bull; | • | bullet |
| &# 9829; or &amp;hearts; | ♥ | black heart |
| &# 9830; or &amp;diams; | ♦ | black diamond |
| &# 9827; or &amp;clubs; | ♣ | black clubs (shamrock) |
| &# 9824; or &amp;spades; | ♠ | black spade |
| &# 8734; | ∞ | infinity symbol |
| &amp;mdash; | — | long dash |

Note: Remove Space between “&#” and “9829” for black heart. Other symbols are the same.

## Using Character Entities in WordPress

Using *character entities* can be a fun part of your design! You can use these special accents with [template tags](https://codex.wordpress.org/Template_Tags) such as the [the_category()](https://codex.wordpress.org/Template_Tags/the_category) tag. Note: [the_category()](https://codex.wordpress.org/Template_Tags/the_category) [template tag](https://codex.wordpress.org/Template_Tags) lists, in [*post meta data*](https://codex.wordpress.org/Post_Meta_Data_Section) section, the various [categor](../../wordpress-overview/where-to-start/wordpress-glossary.md#category)[ies](https://codex.wordpress.org/Glossary#Category) assigned to a [post](../../wordpress-overview/where-to-start/wordpress-glossary.md#post).

In this example, the special *character entity*, the heart (**♥**) symbol, separates the [categories](../../wordpress-overview/where-to-start/wordpress-glossary.md#category) of WordPress, Computers, and Internet News:

```
<?php the_category(' &hearts; ') ?>
```

> [!NOTE]
> WordPress ♥ Computers ♥ Internet News

In this example you see the use of an accent in your [post’s title](https://codex.wordpress.org/Template_Tags/the_title):

```
<?php the_title('∞ ', ' ∞'); ?>
```

> [!NOTE]
> ∞ WordPress Makes Me Smile ∞

If you want to highlight the [post’s author](https://codex.wordpress.org/Template_Tags/the_author), you don’t have to use a character entity inside of a WordPress template tag. You can use it in the text.

```
<div id="author">&diams; <?php the_author(); ?></div>
```

> [!NOTE]
> ♦ Harriet Smith

As you have seen, there are a many uses for *character entities* within your site. With this information you can experiment and find creative ways to use these symbols in your design!

**Note:** Not all [template tags](https://codex.wordpress.org/Template_Tags) can use *character entities*, especially those [tags](https://codex.wordpress.org/Template_Tags) that use [boolean parameters](https://codex.wordpress.org/Template_Tags/How_to_Pass_Tag_Parameters#Boolean). Test a [template tag](https://codex.wordpress.org/Template_Tags) <br>
**thoroughly** to be sure that it will accept the symbols.
