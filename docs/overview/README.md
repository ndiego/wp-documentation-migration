# WordPress overview

Learn what WordPress is, where it came from, and how to take your first steps with it.

Start with **Where to start** if you are new to WordPress: it is a short reading path from setting
up your site to understanding the vocabulary used throughout this documentation. **About WordPress**
covers the project's history, versions and community, and **Frequently asked questions** answers the
questions people ask most often.
