# WordPress Versions 0.7 to 4.9

The following are the various versions of WordPress, listed [chronologically](learn-about-wordpress-and-version-history.md) from newest to oldest, along with the [Change Log](wordpress-versions.md#changelog) information on new features and improvements in each version.

**NOTE:** WordPress core developers share a love of jazz music, and since WordPress 1.0, all major releases are named in honor of jazz musicians they admire.
