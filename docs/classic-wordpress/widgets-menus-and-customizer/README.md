# Widgets, Menus and the Customizer

Classic themes are customised in the Customizer (Appearance > Customize) and on the Widgets and
Menus screens. Block themes replace all three with the Site Editor (Appearance > Editor), where
widget areas become template parts and menus become Navigation blocks; see
[Site Editor](../../editing-and-design/site-editor/README.md).
