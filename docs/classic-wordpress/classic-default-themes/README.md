# Classic default themes

The default themes WordPress shipped before Twenty Twenty-Two, newest first. They are classic
themes: you customise them with the Customizer, widgets and menus rather than in the Site Editor.
They still receive security and compatibility updates, so they remain available to install from
the theme directory.

For the default block themes, see
[Default themes](../../editing-and-design/themes/default-themes/README.md).
