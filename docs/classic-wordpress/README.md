# Classic WordPress

These pages cover features you only see on a site that uses a classic theme or the Classic Editor
plugin: the Classic Editor itself and the audio and video shortcodes, the widgets, menus and Customizer
screens of classic themes, and the classic default themes.

A fresh WordPress install ships with a block theme and the block editor, so you may never see these
screens. For the block-first equivalents (the block editor, the Site Editor and block themes), see
[Editing & design](../editing-and-design/README.md).
